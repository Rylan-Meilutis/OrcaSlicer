# OrcaSlicer RME 2.5.0-rme.4

## Highlights

- Add opt-in **Rooting** under Multimaterial: branching buried anchors at vertical model-material contacts, with depth, diameter, spacing and protective-skin controls. Upper-part top layers and exposed surfaces remain unchanged. Generated supports, support interfaces, and support/soluble filaments are excluded.
- Allow regular overhang wall overlap alongside arc overhangs, using local distance thresholds instead of disabling the option globally.
- Improve arc-overhang growth, path ordering and excessive-overlap checks.
- Improve OctoPrint filament synchronization, searchable profile mapping and print/export tool assignment.
- Correct gantry model selection and use directional collision envelopes for sequential arrangement instead of the legacy circular radius where a model is available.
- Fix the printer-settings crash and add instance-level base-filament assignment through the Objects menu.
- Include material-interface speed, bridge/overhang controls, G-code preview improvements, and expanded slicing/export regression coverage.
- Include missing test resources and G-code auditors in Flatpak CI packaging.

## Validation and limitations

The macOS ARM64 development app builds and passes its CLI startup check.
Rooting and multimaterial regressions pass 11 test cases / 5,740 assertions;
Python G-code auditors pass 32 tests. The broader targeted checks pass 80 FFF
cases / 1,227,042 assertions and 127 core cases / 1,827 assertions. Platform
release artifacts are built by CI.

Rooting is disabled by default and is an experimental mechanical-joint feature
within this stable application release. Geometry checks do not establish pull-out
strength: physically test the chosen materials and geometry before structural use.
It can add substantial tool changes. Ineligible roots are skipped rather than
cut into disconnected anchors.

Experimental non-planar generation remains unavailable and is not print-qualified.
Instance filament assignment changes the base filament; it is not per-instance
remapping of painted colors. Live printer/OctoPrint and physical-print verification
remain necessary; automated tests are not hardware certification.
